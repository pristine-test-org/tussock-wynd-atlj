How the list works

Every item on the Tussock Wynd list is stored in one shared table, so what you see on the landing page is always the latest five entries.

  1. Someone adds an item to the shared list.
  2. The landing page asks for the five newest entries when it loads.
  3. Finished items are shown with a tick in front of them.

The list refreshes each time the page is opened.

5 items are shown at a time, newest first.
